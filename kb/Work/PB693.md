# PB693 — LANDED — a reserved word admitted to the name slot

Found 2026-09-05 by the `PB345` implementer (report §"New defects" 1) when its note's repro reproduced only WITH
the periods it printed: written period-less, the UNLOCK statement vanished into the MOVE before it.

## The shape

`moveReceivingPhrase : TO dataReferenceList` consumed `UNLOCK F1` as two more receivers, because the generated
`cobolWord` rule (`src/Cobol.Net.Frontend/Grammar/Core/CobolWords.g4`) admitted `UNLOCK` unguarded. §8.9 lists
UNLOCK among the reserved words and §8.3.2.1 rule 1 says *"Reserved words shall not be used as user-defined words
or system-names"* — and `cobolWord` IS the user-defined-word slot. Any statement ending in a `dataReferenceList`
(DISPLAY, MOVE, …) followed by a period-less UNLOCK had the same shape.

**Repro** (`tests/conformance/2002/pb693_unlock_after_periodless_move.cob` is the golden form): `MOVE "ZZ" TO FS`
then `UNLOCK F1` on the next line, no period between, at `--std 2002/2014/2023` → `COBOLNET1639 'UNLOCK' is not
defined`, `COBOLNET1639 'F1' is not defined`, `COBOLNET0901`. Now compiles and runs.

## Landed

The one-row fix the note proposed was not the fix. Five rows carried a hand-set `reservationGated` flag; **fifty-one
more name-slot words straddle a §8.9 boundary and none had one**, and nothing could see it. So the flag is gone and
the gate is DERIVED (CLAUDE.md rule 5):

- `scripts/gen-cobol-words.ps1` step 4b computes the gate set from `reserved-words.json` — a `nameSlot` row whose
  word §8.9 reserves at ≥1 edition — and THROWS if a `reservationGated` property ever reappears in the JSON. 58
  gated words, up from 5.
- **One derived exclusion:** the §15 intrinsic function names that collide with a reserved word, read from the
  `functionName` rule (LENGTH, NATIONAL, BIT). A `cobolWord` occurrence of one is the keyword-omitted function
  reference (`COMPUTE N = LENGTH(A)`), a use OF the reserved word; gating them turned five conforming 2023 goldens
  into COBOL0001. They lead no statement and no clause, so they carry no swallow risk.
- The predicate is `userWordHere("W")` = `reservedHere` **plus the migration mode**. `--permissive` accepts what an
  edition removed and a word §8.9 took away is exactly that, so the gate is strict-only — otherwise the whole class
  becomes a parse error no severity policy can downgrade. Wiring that up exposed a second defect: `Frontend.cs` set
  only `DialectLevel` on the parser, so `Edition.Permissive` was false for **every** real compile.
- The declaration re-admission (`reservedGatedWord`, the inverse predicate) now covers every definition slot the
  §8.9 funnel screens — `dataName`, `programName` (§11.10.2), `sectionName`/`paragraphName` (§14.4.2/§14.4.3) and
  the SELECT file-name (§12.4.5.1) — and it sits on the DEFINITION WRAPPERS, never on `procedureName`/`fileName`
  themselves, whose REFERENCE lists would re-open the swallow. The funnel arm moved from `VisitDataName` to
  `VisitReservedGatedWord` — the rule — so a new definition slot needs no C# at all.
- A **REFERENCE** to a gated word has no name-slot alternative left, and a source that fails to parse never reaches
  the bound-tree funnel. `CobolErrorListener` therefore re-codes such a syntax error to COBOLNET0901 using the
  generated `CobolLexer.IsReservationGated` set and the one message `ReservedWordSet.UserWordViolationMessage`
  owns — so the cause is now NAMED in reference position, which the conservative funnel never screened at all.
- `CobolWordsDriftTests.CobolWordsG4_ReservationGate_Is_Derived_From_Section89` recomputes the derivation
  independently and pins both halves plus the confidence alignment. It fired RED on the pre-fix tree
  (`§8.9 requires 61 gated alternatives, the grammar has 5`) and green after.

Goldens: `tests/conformance/2002/pb693_unlock_after_periodless_move`, `tests/conformance/85/`
`pb693_enter_after_periodless_move` (the 85-reserved direction — ENTER) and `pb693_reserved_words_as_data_names`
(nine gated words as data-names at 85), `tests/conformance/negative/pb693-program-id-reserved-word`.

Same family as [[PB655]]/[[PB657]] (the reserved-word funnel's reach) and [[PB300]]/[[PB301]]/[[PB137]] (the gate
this generalizes).
